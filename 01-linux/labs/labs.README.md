# Labs - OverTheBandit

Labs completed as part of the Linux module at CoderCo.

| Lab | Topic |

| [Level 9](./otb-level9.md) | Finding human-readable strings in a binary file |
| [Level 10](./otb-level10.md) | Decoding a base64 encoded file |
| [Level 11](./otb-level11.md) | ROT13 cipher decoding with `tr` |
| [Level 12](./otb-level12.md) | Reversing a hex dump and decompressing files |
| [Level 13](./otb-level13.md) | SSH with a private key |
| [Level 14](./otb-level14.md) | Sending data over a network port with `nc` |
| [Level 15](./otb-level15.md) | SSL/TLS encrypted connection with `ncat` |
